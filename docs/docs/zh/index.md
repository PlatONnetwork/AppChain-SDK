# What is the AppChain SDK
AppChain-SDK 是 PlatON L2 层基于 Giskard-BFT 共识的应用链开发框架

AppChain-SDK 的目标是能够让开发者开发简单的构建自定义区块链，能够与L1及L2链进行互操作。我们希望AppChain-SDK 能够成为区块链的基础构建框架，基于 AppChain-SDK 的区块链由可组合的Modules组成，Modules 开源并且任何人都可以为AppChain-SDK 提供开发模块，
模块开源并且能被其他开发者所利用，开发者可以自由组合模块来定义全新的区块链应用


# Why the AppChain SDK

AppChain-SDK 应用链开发框架是目前最先进的开发框架，以下几点可能是是考虑 AppChain-SDK 的原因

* 全面兼容以太坊，AppChain-SDK 使用Solidity语言，并以太坊RPC协议， 以太坊生态中的应用可以无缝迁移到 AppChain-SDK 应用链

* Giskard-BFT，Giskard-BFT 是目前最高效、安全的BFT协议，基于Giskard-BFT 共识可以自定义验证人数量，出块速度等

* 开放的模块框架，AppChain-SDK 为开发者提供全面的模块开发能力，开发者可以利用官方提供的模块满足基础需求，同时开发者可以对区块、共识、P2P、RPC、合约、存储等进行定制化开发，
